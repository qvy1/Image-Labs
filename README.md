## Lab 1 — Basics of Programming with Python

**Outcome #1:** Explain how digital images are represented and manipulated in a computer.

### Tasks covered

| Task | Description |
|------|-------------|
| Task 0 | Environment check and preparing the `images/` folder |
| Task 0b | The scikit-image general-purpose image dataset (course resource) |
| Task 0c | Building an image from scratch with NumPy |
| Task 1 | Python & NumPy practice from the course cheat sheets |
| Task 2 | Loading and visualizing images with OpenCV and PIL |
| Task 3 | Saving images to disk with OpenCV and PIL |
| Task 4 | Displaying an image as a NumPy array |
| Task 5 | Assessment — NumPy operations on the image array |

### NumPy operations demonstrated in Task 5

Statistics · cropping by slicing · horizontal and vertical flipping · transposing ·
brightness adjustment with `np.clip` · negative (`255 - x`) · thresholding with boolean
indexing · downsampling by step slicing · `vsplit` / `vstack` / `hstack` / `dstack` ·
histogram with `np.histogram` · masking with a computed condition.

## How to run

1. Clone this repository or download it.
2. Open a terminal in the repository folder and start Jupyter:
   ```bash
   jupyter notebook
   ```
3. Open `Lab1_Image_Processing.ipynb`.
4. Run all cells in order (**Cell → Run All**).

The notebook creates the `images/` and `output/` folders automatically on the first run,
so no manual file setup is needed.

## Notes

- The images used in this lab come from the course resource, the
  [scikit-image general-purpose images gallery](https://scikit-image.org/docs/stable/auto_examples/data/plot_general.html).
  Task 0b displays the whole dataset and compares the arrays behind each image, Task 0c
  reproduces the second figure from that page and draws images from scratch with NumPy, and
  Task 0 writes two samples into `images/` so the code from the lab manual runs unchanged.
  If the files already exist in `images/`, they are used as they are and nothing is overwritten.
- Almost all of these samples are bundled with scikit-image and work offline. One of them
  (`eagle`) is downloaded on demand and needs the optional `pooch` package; the notebook skips
  it gracefully instead of raising an error.
- OpenCV loads colour images in **BGR** order while Matplotlib expects **RGB**. Task 2 shows
  both versions side by side and performs the conversion with `cv2.cvtColor`.
